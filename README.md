# Avtero

AI-сервис подбора автозапчастей по VIN для российского рынка. Он помогает превратить запрос владельца автомобиля в структурированный список подходящих деталей и ориентиров для поиска.

## Для кого

- владельцам автомобилей, которые ищут запчасть по VIN;
- автосервисам и специалистам по подбору;
- магазинам и каталогам, которым нужен структурированный результат подбора.

## Что умеет

- декодировать VIN и уточнять совместимость;
- находить OEM-номера и кросс-номера;
- сопоставлять доступные предложения из профильных каталогов;
- собирать контекст по отзывам и альтернативам;
- выдавать структурированный список деталей, а не свободный текстовый ответ.

## Как работает

Пользователь передаёт VIN и описание задачи. Сервис последовательно уточняет автомобиль, получает данные по оригинальным и альтернативным номерам, проверяет доступность и формирует итоговую подборку. Источники и ответы проходят валидацию перед выдачей.

Avtero — инструмент для предварительного подбора; совместимость, наличие, цена и условия покупки всегда требуют подтверждения у продавца или специалиста.

## Доступ

- Сайт: [avtero.codoceh.ru](https://avtero.codoceh.ru)
- Telegram-бот: [@avtero_bot](https://t.me/avtero_bot)

Сайт и бот используют единый продуктовый контур: запрос можно начать в удобном интерфейсе, а итоговую подборку получить в соответствующем канале.
